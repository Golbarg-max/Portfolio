FinTerminal

A Bloomberg-inspired market terminal for checking your portfolio from the command line.

  • Go CLI built on Cobra, with quote and portfolio add / remove commands that print colour-coded tables.
  • Pulls live quotes from the Alpha Vantage API and calculates gain/loss, ROI and totals against each holding's cost basis.
  • A server command exposes the same data as a REST API with a web dashboard.

team of 4 · hackathon · oct 2026

Motif

A browser app that lets someone communicate using any small movement they can comfortably repeat.

  • Learns a person's own movement, like an eyebrow raise or a small head turn, from the webcam using MediaPipe face landmarks.
  • Each movement must pass separate checks before it controls anything. Motif then scans through phrase groups, and a held movement picks a phrase and speaks the message.
  • Camera images and measurements never leave the device.
  • TypeScript
  • MediaPipe
  • Supabase
  • Vitest
